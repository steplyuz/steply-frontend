# O‘zgarishlar (2026-11-20)

## 1. Havolalar (URL) tuzatildi
- `/dashboard/{reading|listening|writing|speaking}` — bunday sahifalar mavjud emas edi (404).
  Endi `/dashboard/cefr?skill=...` ga yo‘naltiriladi:
  - features/dashboard/components/study-path-wizard.tsx
  - features/speaking/components/speaking-locked.tsx
  - test sahifalaridagi “orqaga” tugmalari (listening, speaking, writing [id])
- `/dashboard/speaking/ai` — `[id]` marshruti “ai” id bilan ochilardi (noto‘g‘ri). Endi `/dashboard/cefr?skill=speaking`.
- `/mock` (bosh sahifa va final CTA) — mavjud bo‘lmagan sahifa. Endi `/dashboard/mock-exams`.

## 2. Natija sahifasi
- `/dashboard/writing/results/[id]` — yozma ish natijasi sahifasi qo‘shildi
  (app/(dashboard)/dashboard/(shell)/writing/results/[id]/page.tsx).
  AI tekshiruv, o‘qituvchi tekshiruvi so‘rovi va PDF yuklab olish shu yerda.

## 3. Test id sahifalari
- reading/listening/writing/speaking `[id]/layout.tsx` — `ai`, `start`, `results`, `me`, `new`
  kabi maxsus so‘zlar test id sifatida ochilmaydi (ro‘yxat: features/practice/lib/access.ts).

## 4. Premium testlar
- features/practice/components/premium-test-guard.tsx — obunasi yo‘q foydalanuvchiga
  qulflangan (is_locked) testni ochmaydi, PremiumGate ko‘rsatadi.
- Mock imtihon (?mode=mock) bu tekshiruvdan o‘tkazilmaydi.
- Katalogni yuklab bo‘lmasa test ochilmaydi, qayta urinish tugmasi chiqadi.
- Server baribir 403 qaytaradi (asl himoya backendda).

## 5. Tarjimalar
- shared/i18n/dict/en.ts va ru.ts: 33 tadan yangi tarjima qo‘shildi (kalitlar dublikatsiz).
